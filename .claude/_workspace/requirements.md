# N-Queens Puzzle Web Application 요구사항 정의서

## 1. 프로젝트 개요
- **목적:** 알고리즘 고전 문제인 N-Queens를 사용자가 직접 플레이해 볼 수 있는 반응형 웹 게임 구축
- **시스템 범위:** 백엔드 DB 없이 100% 클라이언트(Next.js App Router + React 19)에서 동작하는 프론트엔드 단독(FE-only) 애플리케이션

## 2. 핵심 기능 요구사항
1. **보드판 설정**
   - 정사각형 형태의 체스 보드를 렌더링한다.
   - 보드 크기(N)는 최소 4x4에서 최대 8x8까지 지원한다.
   - 화면 상단에 N의 크기를 조절할 수 있는 UI(Select Box 또는 버튼)를 제공하며, 크기 변경 시 보드는 즉시 초기화된다.

2. **퀸(Queen) 배치 및 취소 로직 (Toggle 방식 적용)**
   - 빈 보드 칸을 클릭(터치)하면 퀸이 배치된다.
   - 이미 퀸이 배치된 칸을 다시 클릭(터치)하면 퀸 배치가 취소된다. (모바일 터치 환경을 고려하여 우클릭 대신 좌클릭 토글 방식으로 통일)

3. **제출 및 검증 (Submit Validation)**
   - 화면 하단에 [제출] 버튼을 제공한다.
   - 사용자가 보드 크기(N)보다 적은 수의 퀸을 배치하고 제출할 경우, "N개의 퀸을 모두 배치해주세요"라는 경고 알림(Toast)을 띄우고 검증을 진행하지 않는다.
   - N개의 퀸을 모두 배치한 후 제출하면 다음 검증 로직이 실행된다:
     - **오답 (Red):** 같은 행, 열, 또는 대각선 상에 겹치는(공격 경로에 있는) 퀸이 하나라도 존재할 경우, 충돌이 발생한 퀸들의 칸 색상을 '빨간색(Red)'으로 변경한다.
     - **정답 (Green):** 모든 퀸이 서로 공격할 수 없는 올바른 위치에 배치되었다면, 모든 퀸의 칸 색상을 '초록색(Green)'으로 변경한다.

4. **보드 초기화**
   - [초기화] 버튼을 제공한다. 버튼 디자인은 '원형 화살표 아이콘이 중앙에 있는 정사각형 버튼'으로 구현한다.
   - 클릭 시 보드에 배치된 모든 퀸이 제거되고 타일 색상이 기본값으로 돌아온다.

## 3. UI/UX 및 디자인 요구사항
- **테마:** 심플하고 모던한 '모노톤(Monotone)'을 메인 컬러 팔레트로 사용한다.
- **반응형:** 모바일 뷰포트부터 최대 2440 x 1440 해상도 대형 모니터까지 보드가 화면 중앙에 적절한 비율로 유지되도록 반응형(Responsive)으로 구현한다.
- **애니메이션:** 퀸이 배치되거나 타일 색상이 변경될 때 일관된 속도와 easing을 가진 부드러운 트랜지션(Transition) 애니메이션을 적용한다.
- **헤더(Header):** "N-Queens Problem" 이라는 타이틀 텍스트만 심플하게 배치한다.
- **푸터(Footer):** 화면 최하단에 "Copyright © nyj001012" 문구를 고정으로 배치한다.
